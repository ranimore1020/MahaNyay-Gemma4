# MahaNyay Pune ⚖️ - Gemma 4 Powered

**पुणे कायदा मित्र | Pune Citizen Legal Aid, BNS Guidance & Complaint Portal**

Live App: https://mahanyay-gemma4-drjebe4kqsggy76gm3e3bl.streamlit.app/

### 🚀 About
MahaNyay is an AI-powered legal aid platform for Pune citizens. Built on Google Gemma 4 (27B), it provides instant legal guidance in Marathi & English under Bharatiya Nyaya Sanhita (BNS).

### ✨ Features
- कायदा सल्ला (Legal Advice)
- तक्रार अर्ज मसुदा (Complaint Draft)
- 7/12 Photo Vachak
- Pune Madat Kendra
- Voice Query

### 🛠️ Tech Stack
- LLM: Gemma 4 27B-IT
- Frontend: Streamlit
- Deployment: Streamlit Community Cloud
